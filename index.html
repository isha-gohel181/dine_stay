1. Executive Summary & Project Deliverables

The DineStay platform delivers a unified 3-in-1 hospitality reservation ecosystem covering Restaurant Table Bookings, Hotel Room Stays, and Banquet / Party Hall event inquiries across Chandigarh and surrounding regions.

DeliverablePlatformTechnology Stack
Customer Mobile ApplicationAndroid & iOSFlutter 3.x / Dart (35 Complete UI Screens)
Restaurant Business PortalWebReactJS / TailwindCSS
Hotel Business PortalWebReactJS / TailwindCSS
Party Hall Business PortalWebReactJS / TailwindCSS
Administration PortalWebReactJS / Admin Dashboard
Backend Core ServicesCloud REST APILaravel 11 REST API / JWT Authentication
Database LayerCloud ServerMySQL 8.0 & Redis Cache
